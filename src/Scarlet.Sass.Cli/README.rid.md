# Scarlet.Sass.Cli.*

This package is a per-platform implementation detail of
[`Scarlet.Sass.Cli`](https://www.nuget.org/packages/Scarlet.Sass.Cli/), restored automatically for you by
`dotnet tool install`/`dotnet tool restore`. It carries no library assets, so `dotnet add package` on it
installs nothing usable.

Install `Scarlet.Sass.Cli` instead:

```bash
dotnet tool install --global Scarlet.Sass.Cli
```

See [`Scarlet.Sass.Cli`](https://www.nuget.org/packages/Scarlet.Sass.Cli/) for full documentation.
