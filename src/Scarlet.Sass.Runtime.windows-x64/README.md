# Scarlet.Sass.Runtime.windows-x64

This package contains the official Dart Sass runtime for windows x64.

Scarlet.Sass.MSBuild does not depend on this package directly. Reference the runtime package that matches the build host, and Scarlet.Sass.MSBuild will discover it through the SassRuntimePack item contributed by this package.

The package version corresponds to the Dart Sass version it contains.
